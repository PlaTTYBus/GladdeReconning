# grecon.fish

> **Gladde Reconning** — OSCP initial recon sweep

## Load it

```fish
source ./grecon.fish   # then run: grecon
```

## Or autoload it permanently

```fish
ln -s (realpath ./grecon.fish) ~/.config/fish/functions/grecon.fish
```


## Output

Outputs land in `./output/`, greppable where the tool allows.
